## 🚀 Daily Execution Workflow

### Step 1: Find Producers (30-45 min)
**Location**: Twitter/X search  
**Search Terms**:
```
"beat seller" OR "selling beats" since:2026-04-07
#beatmakers #trapproduction (filtering for links in bio)
beatstars producer 
"just sold" "beat"
```

**Criteria**:
- ✅ Bio has Beatstars/Gumroad/store link
- ✅ Recent active posts (within 7 days)
- ✅ Engagement 50+ per post
- ✅ Not already contacted (check OUTREACH-LOG.md)

**Output**: Document 10 handles in OUTREACH-LOG.md with:
- Handle & follower count
- Genre/focus
- Recent post content (for personalization)

### Step 2: Personalize Messages (15-20 min)
Use message templates from BRO-125-TARGET-PRODUCERS.md:

**Key elements**:
- Address pain point they've mentioned
- Show understanding of their platform/genre
- Highlight BroLab advantage (0% commission, instant delivery)
- Include signup link
- Keep it brief (2-3 sentences max)

**Personalization hack**: If they mentioned "commission" in recent post, use Template A. If they talked about "delivery," use Template B. Generic = Template C or D.

### Step 3: Send DMs (30-45 min)
1. Open each producer's DM on Twitter/X
2. Paste personalized message
3. Send
4. Document in OUTREACH-LOG.md:
   - Time sent
   - Message variant used
   - Status: ✅ Sent

### Step 4: Track & Follow Up
- **Day 1-2**: Monitor for responses (don't expect immediate replies)
- **Day 3+**: Follow up with non-responders if relevant
- **Document everything**: Response time, engagement level, conversion signals

**Tracking columns**:
| Handle | Sent | Response | Type | Positive? | Signup? | Notes |
|--------|------|----------|------|-----------|---------|-------|
| @xyz   | 4/7  | Yes      | Q    | Yes       | No      | Asked about pricing |
